## Reproduced gap

The sanitizer already promised exact/original/NFC configured values and URL-quoted
forms. However, percent escapes generated by quote/quote_plus used uppercase hex,
and literal matching missed semantically equivalent lowercase or mixed-case hex
inside nested strings and immutable artifact bytes. A synthetic configured value
`Synthetic/Canary+Ω` could appear as `Synthetic%2fCanary%2b%ce%a9` without redaction
or artifact rejection. Explicit URL fields were separately decoded and were not
this missing case.

## Corrected boundary

Only generated URL-quoted variants gain case-flexible hexadecimal digits inside
`%HH` escapes. Ordinary letters remain case-sensitive. Raw secret values containing
literal percent sequences remain literal unless another configured secret independently
makes that spelling a generated quoted form. NFC/original spellings and quote_plus
space handling retain their previous scope. Base64 forms remain case-sensitive.

The matcher uses fixed character classes per escape, not enumeration of mixed-case
permutations. Inputs remain bounded by existing 64-secret/4096-byte limits. Both
text and UTF-8 byte matchers derive from the same escaped configured variants;
caller input is never interpreted as a regular expression. The byte matcher rejects
immutable artifacts without decoding, rewriting or changing accepted digests.
Text redaction still precedes truncation. Residual serialized/rendered scans use
the same matcher, so lower/mixed escapes cannot bypass a later invariant check.

This is not arbitrary URL decoding, recursive transformation, unknown-secret
recognition, case-insensitive credential matching, or binary-format inspection.
Double-encoded variants are not added implicitly. Existing URL-field handling,
projection schema, authority, SQLite schema and public APIs remain unchanged.

## Evidence

`tests/test_percent_case.py` checks uppercase/lowercase/mixed-case reserved and
UTF-8 escapes, original/NFC variants, plus-versus-percent spaces, truncation,
unsafe encoded keys and ordinary-character case-sensitive negative cases.
Independent observers scan escaped rendering, real SQLite rows/database bytes,
and a fresh-process database read. UploadJournal rejects dirty artifacts before
reservation or provider calls; artifact bytes remain untouched. All values are
invented synthetic canaries and sockets are denied.

A disposable mutation restores case-sensitive escape matching. The projection and
artifact observer regressions must fail by assertion rather than an import error.
A many-escape fixture checks bounded pattern representation without exponential
variant enumeration. Existing sanitizer regressions remain required.

Reproduce with `python3 -m unittest discover -s tests -p test_percent_case.py -v`,
repeat with `python3 -O`, then run `python3 tools/validate.py` and the complete
optimized suite with the existing pinned quality tools. No packages or services
are installed. The issue's broader adapter, authority and live acceptance gates
remain open.
